# خطة استكمال الميزات الناقصة — UR-SEHR

## ما تم إنجازه حتى الآن
- بوابة دخول موحّدة (8 أدوار + تحقق NFC/بصمة/وجه/OTP محاكى)
- لوحات: المواطن، الطبيب، الممرض، المختبر، الأشعة، الطوارئ، الوزارة، الصيدلي، صحة المجتمع، العلاج الطبيعي
- حجز مواعيد، إحالات، رفع تقارير، تنبيهات، سجل الأسرة، تنبيهات وطنية، تسجيل بطاقة صحية

## الميزات الناقصة من الأوامر النهائية

### 1. الذكاء الاصطناعي والتشخيص المساعد
- اقتراحات تشخيص ذكية موسّعة في لوحة الطبيب (تحليل الأعراض + التاريخ المرضي)
- تنبيهات ذكية للقيم الشاذة في التحاليل والأشعة

### 2. نظام التأمين الصحي
- ربط الوصفات والمواعيد بحالة التأمين
- عرض نسبة التغطية والمبلغ المتبقي على المواطن

### 3. وضع العمل بدون إنترنت
- حفظ البيانات محليًا عند الانقطاع (موجود جزئيًا عبر localStorage)
- مؤشر حالة الاتصال + مزامنة تلقائية عند عودة الاتصال

### 4. وضع الكوارث (لوحة الطوارئ)
- فرز الإصابات (تصنيف ألوان: أحمر/أصفر/أخضر)
- تتبع سيارات الإسعاف على خريطة مبسطة
- تتبع الأسرّة المتاحة ومراقبة الضغط على المستشفيات

### 5. نظام البحث العلمي
- لوحة باحثين جديدة: بيانات مجهولة الهوية فقط (بدون اسم/رقم وطني/هاتف/عنوان)
- إحصائيات وتقارير بحثية

### 6. دعم اللغات وإمكانية الوصول
- مبدّل لغة: العربية / الكردية / الإنجليزية
- وضع الخط الكبير
- دعم القراءة الصوتية (قارئ شاشة أساسي) وتباين عالٍ لذوي الإعاقة البصرية

### 7. محرك التداخلات الدوائية
- فحص تلقائي عند إنشاء وصفة: حساسية + تداخلات بين الأدوية الفعّالة

## تفاصيل تقنية
- كل الميزات تبقى نموذجًا تفاعليًا (localStorage) — لا حاجة لقاعدة بيانات حاليًا
- توسيع `app-store.ts` (تأمين، كوارث، لغة، إمكانية وصول)
- ملف ترجمة بسيط `src/lib/i18n.ts` للغات الثلاث
- مكوّنات جديدة: `AccessibilityMenu`, `LanguageSwitcher`, `OfflineIndicator`
- لوحة الباحثين: مسار جديد `/research`

## ترتيب التنفيذ المقترح
1. وضع الكوارث + فرز الإصابات (الطوارئ)
2. محرك التداخلات الدوائية (الطبيب/الصيدلي)
3. التأمين الصحي (المواطن/الصيدلي)
4. اللغات + إمكانية الوصول (عام)
5. وضع عدم الاتصال + مؤشر المزامنة
6. لوحة البحث العلمي
